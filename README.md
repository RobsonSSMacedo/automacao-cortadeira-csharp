# Contador de Produção Industrial (Integração C# & Excel)

## 📌 Sobre o Projeto
Biblioteca de vínculo dinâmico (DLL) desenvolvida em C# para automação industrial de chão de fábrica. O sistema realiza a comunicação com o maquinário produtivo para efetuar a contagem automatizada de cortes em uma cortadeira de blocos cerâmicos, exportando e consolidando os dados diretamente em planilhas Microsoft Excel em tempo real.

## 🛠️ Problema Resolvido
* *Antes:* Contagem manual ou suscetível a falhas humanas no inventário de produção.
* *Depois:* Automação total do registro de refugo e peças prontas, eliminando gargalos de auditoria e gerando relatórios instantâneos para a gerência.

## 🚀 Tecnologias Utilizadas
* *Linguagem:* C# (.NET Core / .NET Framework)
* *Integração:* COM Interop / ClosedXML / EPPlus (Manipulação de planilhas)
* *Arquitetura:* Biblioteca de Classes (DLL) para reaproveitamento de código

## 📊 Impacto Operacional
* Redução do tempo de fechamento de turnos industriais.
* Confiabilidade de 100% nos dados de produtividade gerados.
* Integração limpa com ferramentas já utilizadas pela empresa (Excel), gerando custo zero de infraestrutura de software.
